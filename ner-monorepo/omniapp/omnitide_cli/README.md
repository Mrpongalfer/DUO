# Omnitide CLI

A Python Typer-based CLI to orchestrate Omnitide agents and tasks.

## Setup
Ensure dependencies from the main `omniapp/requirements.txt` are installed in your virtual environment.
If using poetry for this sub-module (see pyproject.toml), navigate here and run `poetry install`.

## Usage
From the `omniapp` root (with venv active):
`python -m omnitide_cli.main --help`
Or if installed via poetry/pyproject.toml:
`omni-cli --help`
