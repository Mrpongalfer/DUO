## 1. Single-Command Context Capture
```bash
nexus-capture --full --output=project_state.nexus
```
Captures:
- Raw terminal history
- All chat logs
- System state snapshots
- Git commit hashes + diffs
- Ansible vault contents (encrypted)
- Contextual embeddings

## 2. Context-Aware Transfer File Structure
- Explicit Layer: Commands, code/configs
- Nuanced Layer: Strategic context, temporal relationships
- Mesh Layer: Semantic embeddings

## 3. One-Line State Transfer
```bash
nexus-export --encrypt --key=quantum2025 | \
ssh aiseed@192.168.0.95 "nexus-import --restore"
```

## 4. Continuous Context Mirroring
- Systemd service for real-time context sync
- Monitors file changes, terminal I/O, mental models

## 5. Human-Verifiable Context

```bash
nexus-browse project_state.nexus
```
