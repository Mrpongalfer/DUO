# Agent Blueprints

This directory contains the unified blueprints, templates, scripts, and documentation for all core and auxiliary agents in the Omnitide Nexus Protocol Toolkit (NPT).

## Contents

- **ex_work_agent/**: ExWorkAgent blueprints, templates, and documentation.
- **scribe_agent/**: Scribe agent profiles and docs.
- **lily_memory_tasks/**: Lily memory extraction and log parsing tasks (reference only; Lily’s core logic is not modified).
- **quantum_orchestrator_prompts/**: Multi-agent orchestration directives and advanced agent system prompts (migrated from Quantum Orchestrator and related projects).
- **ekko_cli.sh**: Unified CLI script for Ekko automation.
- **gather_nexus_info.sh**: Unified info-gathering script (from Chimera Ansible configs).
- **oda_core_operative_blueprint.py**: ODA core operative blueprint.
- **omnitide_templates.json**: Omnitide template definitions (from Gotted).
- **ex_work_agentv2.py, ex_work_agent_wizardpro2.py**: Unified ExWorkAgent variants from NAI and WizardPro2.

All assets here are deduplicated and synthesized from legacy and current projects, ensuring a single source of truth for agent logic and automation.
