# Nexus Edict Repository (NER)

The Nexus Edict Repository (NER) is the **single source of truth** for all automation, agent, protocol, and knowledge assets within the Omnitide Nexus Protocol Toolkit (NPT). All blueprints, templates, agent logic, operational mandates, and core knowledge from legacy and current projects are unified here.

## Repository Structure

- **00_CORE_EDICTS/**: Foundational edicts and operational mandates for the Omnitide Nexus.
- **01_ONAP_R3_COMPONENTS/**: Structured prompts for LLM imprinting and ONAP activation.
- **02_TPC_STANDARD/**: TPC (Top-tier Performance & Coder) standards and compliance documentation.
- **03_CORE_TEAM_PERSONAS/**: Core Team persona profiles for simulation and feedback loops.
- **04_INTERACTION_GUIDES/**: Best practices and protocols for interacting with Nexus AI agents.
- **05_PROJECT_SUMMARIES/**: Overviews and summaries of key projects and components.
- **06_AGENT_BLUEPRINTS/**: Unified blueprints, templates, scripts, and documentation for all core and auxiliary agents (including ExWorkAgent, Scribe, Quantum Orchestrator, ODA, Ekko, and more).
- **07_SECURITY_TOOLS/**: Security tools, templates, and operational blueprints.
- **08_INNOVATION_SHOWCASE/**: Experimental tools, hackathon resources, and proof-of-concepts.

## Migration & Synthesis

All unique, non-Lily knowledge assets from legacy projects (chimera-ansible-configs, ekko, gotted, NAI, ODA, quantum_orchestrator_app, wizardpro2, etc.) have been deduplicated, synthesized, and migrated into the appropriate subfolders above. **Lily’s persona and logic remain pristine and unmodified.**

## Usage

This repository is the authoritative reference for all automation, agent orchestration, and operational standards in the Omnitide Nexus. All new development, agent evolution, and system integration must reference and extend from these assets.
