# DUO Monorepo (2025)

## Overview
This is the unified, production-grade monorepo for the DUO autonomous agent ecosystem, Omnitide Nexus, and related projects. All code, agents, orchestrators, and tools are now deduplicated and streamlined for perpetual self-improvement, robust automation, and developer/ops productivity.

## Key Directories
- `games/nexus_omniengine_v3/` — Canonical Omniengine source, agents, configs, docs, tests, and GUI.
- `games/Lily/` — Lily context manager and core memory modules.
- `goal_vectors/` — Vector embeddings and guiding principles.
- `lilyAI/` — Lily AI projects, context, and setup scripts.
- `optimal/` — Diagnostics, orchestrators, and k8s configs.
- `Omnitide_Architects_Presence_Discretion_And_Value_Actualization_System/` — OAPDVAS system and services.
- `scripts/` — Utility and automation scripts.
- `Rules/` — Project and protocol rules.

## Core Agents & Scripts
- `exworkagent0.py` — Ex-Work Agent (task execution, learning)
- `scribe0.py` — Scribe Agent (validation, review, integration)
- `heal_project.py` — Automated project healing and deduplication
- `lazymonorepo.py` — TUI/CLI for orchestration, diagnostics, and agent management
- `llm_code_generator.py` — LLM-powered code improvement
- `metamorphosis.sh` — Metamorphic Loop orchestrator

## Setup & Usage
- See `setup_duo.sh` for environment setup.
- Use `lazymonorepo.py` for menu-driven automation, healing, and agent orchestration.
- All agents/scripts are now referenced from canonical locations (see `lazymonorepo_config.yaml`).

## Structure
- All duplicate, empty, and legacy folders have been removed.
- Only functional, canonical code and config remain.
- All caches, .pyc, .egg-info, .venv, and .vscode folders are purged from submodules.
